# VocabMaster - 英语词汇智能提取工具

基于 Streamlit 的英语词汇提取与词书生成工具，支持从字幕、电子书、文档中智能提取生词，自动词形还原、词频统计、例句匹配，一键生成专属词书。

## 核心功能

- **双引擎词形还原** — NLTK（快速，POS 标注精准还原）和 spaCy（高精度 Transformer 模型），run/ran/running → run
- **词频统计** — 按出现次数降序排列，优先学习高频词汇
- **上下文例句** — 自动匹配原文中每个词的第一条例句，学词不忘语境
- **熟词屏蔽** — 内置小学/中考/高考预置词库，自动过滤已掌握的简单词汇
- **多格式支持** — 支持 `.txt`、`.srt`、`.ass`、`.docx`、`.pdf` 等文件格式直接上传
- **多格式导出** — 支持 TXT 纯单词列表、CSV（兼容 Anki 直接导入，包含词频+例句）
- **公共词书库** — 提取结果可发布到社区词书库，也可浏览下载他人分享的词书

## 技术栈

- **前端**: Streamlit（Python Web UI）
- **NLP**: NLTK（词形还原、词性标注、停用词、分句）+ spaCy（高精度 Transformer 模型）
- **文档解析**: python-docx（Word）、PyPDF2（PDF）、chardet（编码检测）
- **存储**: 本地文件系统 + GitHub API（云端词书库同步）

## 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
```

打开浏览器访问 `http://localhost:8501`，粘贴文本或上传文件即可开始提取。

## 使用场景

- 看美剧前提取字幕生词，学完再看事半功倍
- 读英文原著前预处理，扫清词汇障碍
- 备考托福/雅思/GRE，从真题中提取高频词汇
- 英语教师为学生定制分级词书

# VocabMaster - 英语词汇智能提取工具

基于 Streamlit 的英语词汇提取与词书生成工具，支持从字幕、电子书、文档中智能提取生词，一键生成专属词书。

## 核心功能

- **智能词汇提取** — 支持 NLTK（快速）和 spaCy（精准）双引擎，自动词形还原（run/ran/running → run）
- **熟词屏蔽** — 内置小学/中考/高考预置词库，自动过滤已掌握的简单词汇
- **多格式支持** — 支持 `.txt`、`.srt`、`.ass`、`.docx` 等文件格式直接上传
- **公共词书库** — 提取结果可发布到社区词书库，也可浏览下载他人分享的词书
- **一键制卡** — 复制结果直接跳转扇贝网等平台批量制作单词卡

## 技术栈

- **前端**: Streamlit（Python Web UI）
- **NLP**: NLTK（词形还原、词性标注、停用词）+ spaCy（高精度 Transformer 模型）
- **存储**: 本地文件系统 + GitHub API（云端词书库同步）
- **编码检测**: chardet（自动识别文件编码）

## 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
```

打开浏览器访问 `http://localhost:8501`，粘贴文本或上传文件即可开始提取。

## 使用场景

- 看美剧前提取字幕生词，学完再看事半功倍
- 读英文原著前预处理，扫清词汇障碍
- 备考托福/雅思/GRE，从真题中提取高频词汇
- 英语教师为学生定制分级词书
